### Desktop Entries

The idea here is that I want to be able to open TUIs with a single click. I'm wrapping everything with **ST** (my default terminal), which lets me launch these applications from **Coqui** or by clicking icons in **Waybar**.

```nix
desktop = {
    impala = pkgs.makeDesktopItem {
        name = "impala";
        desktopName = "Impala";
        comment = "Wi-Fi TUI";
        exec = "st -e impala";
        terminal = false;
        categories = [ "Network" ];
    };
};
```
